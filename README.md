# 健康追踪 · Health Tracker

一个纯前端的个人健康数据追踪应用，无需后端，数据保存在浏览器本地。

## 功能特性

### 数据记录
- **体重**：每日体重记录，自动计算变化量
- **腰围**：每日腰围记录
- **三餐饮食**：早餐、午餐、晚餐文字记录
- **睡眠**：入睡/起床时间，自动计算睡眠时长（支持跨天）

### 统计分析
- **日/周/月切换**：三种粒度查看趋势
- **体重曲线**：折线图展示变化趋势
- **腰围曲线**：折线图展示变化趋势
- **睡眠柱状图**：每日睡眠时长对比
- **BMI 曲线**：输入身高后自动计算 BMI
- **KPI 卡片**：当前值、起始值、变化量、连续记录天数
- **目标进度**：设置目标体重后显示完成百分比

### 高级统计
- 最高/最低/平均值
- 7 日平均、30 日平均
- 周环比变化、月环比变化
- 睡眠规律评分
- 工作日 vs 周末睡眠对比
- 基础代谢率（BMR）估算
- 理想体重范围
- 周汇总表、月汇总表

### 数据管理
- **本地存储**：数据保存在浏览器 localStorage，不上传服务器
- **导出备份**：一键导出 JSON 文件
- **导入恢复**：从 JSON 文件导入数据
- **PWA 支持**：可安装到手机/电脑桌面，离线使用

## 部署方式

### GitHub Pages（免费）

1. 进入仓库 **Settings** → **Pages**
2. Source 选择 `main` 分支，根目录
3. 几分钟后获得 `username.github.io/repo-name` 的网址

## 安装到手机桌面（PWA）

部署到 HTTPS 网址后：

### iPhone (Safari)
1. 用 Safari 打开网址
2. 点击底部分享按钮
3. 选择「添加到主屏幕」
4. 点击「添加」

### Android (Chrome)
1. 用 Chrome 打开网址
2. 点击右上角菜单
3. 选择「添加到主屏幕」或「安装应用」
4. 按照提示操作

## 隐私说明

- 所有数据仅保存在你的浏览器本地
- 不会上传到任何服务器
- 清除浏览器数据会丢失记录，请定期导出备份

## 技术栈

- 纯 HTML / CSS / JavaScript（零构建）
- Chart.js 图表库
- localStorage 数据持久化
- PWA (Service Worker + Web App Manifest)
- 响应式设计，适配手机/平板/电脑
